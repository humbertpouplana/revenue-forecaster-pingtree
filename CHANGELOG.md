# Changelog

All notable changes. Versions follow `MAJOR.MINOR.PATCH`; the model version is `__version__` in `src/<package>/__init__.py` and is written into `results/results.json`.

## 0.2.0 - 2026-11-05
- Model moved from the HTML prototype to a tested Python package (`src/pingtree_forecaster`); the prototype keeps a JavaScript mirror verified by a parity test.
- New **reach adjustment** (`reach=True`): each partner is only queried for a fraction of the leads. The unadjusted flow (115,371 EUR per 100,000 leads) is documented as a *ceiling*.
- New **reconciliation and walk-forward backtest** against realised revenue (`backtest.py`).
- Dataset moved out of the HTML into `data/partner_monthly.csv` with a data dictionary; partner names pseudonymised.
- All parameters centralised in `data/params.json`; paper, prototype and tests read the same file (fixes the "2 months vs 6 months" inconsistency: means use `aggregation_months`, volatility uses `volatility_from`).
- Figures are generated by `make figures`; paper numbers are filled from `results/results.json`.
- Fixed cross-reference numbers of figures in the paper (labels were placed before captions).
